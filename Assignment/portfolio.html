Project Nova

A battleships style game built in Java. This was my final project during semester 1 for my Software Design and Development module. This was a solo project where I designed and created a 2 person game with a grid-based board. Creatures would be hidden on the board and the other player had to make guesses where they were hiding.

Plant Species Database

This project was the first Java assessment I completed during semester 1 for my Software Design and Development module. This was a solo project where we created a database to store information about different plant species. Plants could be added, sorted by different criteria and searched for by the user.

Subject Quiz

This is the project I designed and built in Advanced Higher Computer Science during my final year of secondary school. The game contained quizzes about different school subjects, questions were randomly generated from a bank and users were able to pick an answer from 3 multi-choice options. The quiz was self marking and I created a leaderboard that users could sort depending on category and score.

Simon Says Game

During this group project, we created a Simon Says style memory game. We connected a webpage and an RGB LED. The light will flash and the useer must click the corresponding button on the webpage. Their score will increase and decrease depending on whether the user is correct or not. There is a maximum of 10 points then the user wins.
